# Demo

`demo/` is live at [effects.lumithemes.com](https://effects.lumithemes.com). It is an Astro site: one gallery of every effect as a working hero, each ShaderBackground and Paper shader on its own, shown one at a time with its own URL (`/#liquid-metal`), filters by type (backgrounds, logos, wordmarks, text, surfaces; `/?type=logos`), arrows and ← → keys to step through them, and a Customise panel to set each one up and copy the line:

```bash
cd demo && npm install && npm run dev   # http://127.0.0.1:4400
```
